# fu3e developer exercise

## The task

A project team needs a simple way to prepare a project register and download it as a CSV file.

We've provided an incomplete Vue / TypeScript and Laravel application. Complete it so a user can:

- Edit column headings and cell values.
- Add columns and rows.
- Remove rows.
- Download the current table as a CSV generated by the Laravel back end.

The exported file should reflect the table shown on screen. Fix any issues you find in the existing behaviour.

You can change the supplied code and structure as you see fit. Keep the solution focused on this task; saving tables, user accounts and additional spreadsheet features aren't required.

## Setup

You'll need PHP 8.3 or 8.4, Composer 2, and Node.js 22.12+ or 24. No database or external service is required.

```sh
composer run setup
composer run dev
```

Open http://localhost:8000/table. If you have trouble running the starter, contact your hiring contact.

The starter also includes these commands:

```sh
composer test
npm run type-check
npm run build
```

## Submission

Upload a ZIP of your solution to a private GitHub repository, give your hiring contact access, and send them the link. Ask them for their GitHub username if needed. Include the files needed to run your solution, excluding installed dependencies and local secrets.

Add a short note in `SUBMISSION.md` covering your approach, how you checked your work, and anything unfinished.

You may use documentation, search and AI tools. Mention any AI assistance in your submission and be prepared to explain your solution.
